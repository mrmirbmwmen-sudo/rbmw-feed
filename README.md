# Автозагрузка Авито — магазин RBMW

Хранилище — единственный источник правды: здесь код, учёт (`state.json`), обработанные фото и сам файл автозагрузки `rbmw.xlsx`, который Авито забирает по ссылке.

## Как работает
`daily.sh` (запускается заданием по расписанию каждый час с 9 до 21 по Москве):
1. `fetch` — скачивает прайс Bazon (CSV, cp1251).
2. `sync` — то, чего нет в прайсе, помечается проданным и уходит из файла; цены приводятся к прайсу.
3. `pick --daily` — первый запуск дня добавляет новые позиции: в первый день `start_batch`, дальше `per_day`.
4. `photos` — скачивает фото Bazon и обрабатывает: поворот ±0.8–1.3°, обрезка 3–4% с каждой стороны, яркость/контраст +5–7%, 1280 px, без EXIF. Параметры зависят от артикула, поэтому одно и то же фото всегда получается одинаковым.
5. `build` — собирает `rbmw.xlsx` по шаблону Авито (листы по категориям, проверка по справочникам).
6. Коммит на GitHub (история не копится, один коммит).

## Правила подбора (config.json)
- цена от `min_price` (15 000 ₽), «В наличии», б/у, есть фото;
- не берём артикулы, которые стоят на 6 аккаунтах коллеги (`data/exclude_colleague.json`) и из `exclude_articles`;
- один OEM — одно объявление; в партии разные наименования и не больше трети на один кузов;
- дорогие первыми.

## Правила Авито в файле (из опыта коллеги)
Вид объявления «Товар приобретен на продажу», страна «Германия», «Происхождение» пустое, TypeID не заполняется, OEM только латиница/цифры/дефис, заголовок до 50 символов без знаков, первая строка описания = заголовок, 2–3 строки синонимов, до 5 кросс-номеров, VIN и условия возврата, акустика в «Аудио- и видеотехника / Другое», селекторы/редукторы/карданы/приводы в «Трансмиссии», Авито Доставка для мелких деталей.

## Команды
```
python3 -I rbmw.py status          # сводка
python3 -I rbmw.py pick 20         # добавить 20 позиций вне расписания
python3 -I rbmw.py build           # пересобрать файл
```
Убрать позицию навсегда: добавить артикул в `exclude_articles` и пометить в `state.json` статус `removed`.
