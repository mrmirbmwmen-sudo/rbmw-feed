## Решения владельца (действуют, пока владелец не отменит)
- Магазин RBMW на Авито: оригинальные б/у запчасти BMW от 2017 года; не дешевле 15 000 ₽.
- Цены меняет только владелец (источник — прайс Bazon). Доставку не трогаем.
- Шаблон объявления менеджера не менять: заголовок = первая строка, 4 строки синонимов, артикул, блок «Покупайте спокойно».
- Любые правки текстов/профиля/аккаунта — только после явного «да» владельца. Не больше 2 правок объявления в сутки (лимит Авито, код 3015).
- Деньги (продвижение, оплаты) включает и выключает только владелец; агенты предлагают план.
- Продвижение: только ручной режим; ≤ 400 ₽/день на аккаунт, ≤ 90 ₽/день на объявление; ставка не выше безубыточности (контакт ≤ 1 000 ₽).
- Подушки безопасности не выставляются до решения владельца.
- Неоригинальные детали помечаются «не оригинал» (config not_original или Производитель ≠ BMW в Bazon).
- Instagram — только имиджевые клипы, без рекламы, цен, призывов и ссылок (закон 72-ФЗ).
- Оформление страницы бренда утверждено 24.11: светлый баннер в цветах логотипа + фото склада, Витрина «Популярное».

## Правила руководства (объявления) — источник: шаблон руководства 09.11 и разбор 19.11; полный текст — документ проекта «RBMW_шаблон_объявления»
- Заголовок = первая строка описания дословно. Порядок: деталь → сторона → BMW → модель → кузов → LCI → год (+ доп. кузова). До 50 символов.
- В заголовке и первых строках — без запятых, скобок, слешей, тире, дефисов, «№», латинских «series»; кузов — с цветом, моторные — с кодом двигателя.
- Описание: заголовок → 4 строки синонимов без знаков → «Артикул товара №…» → состояние «Оригинальная запчасть BMW б/у в наличии в Москве» (для неоригинала — «не оригинал») → комплектация у менеджера → номер детали и до 5 кросс-номеров → «Состояние и комплектность» (комментарий Bazon + «Снято с BMW…») → «Подходит для» → «Перед покупкой пришлите VIN…» → «Покупайте спокойно».
- Нельзя: телефон, ссылки, «Актуально на…», непроверенные утверждения («гарантия», «из Германии» — только если правда), неверная категория, пустые поля фильтров.
- Тексты не править часто (размывает историю объявления): правки копятся и выходят одной загрузкой; меняется только цена из Bazon.
- Фото: до 10, порядок как в Bazon, первое — деталь крупно, не тёмное, без надписей.
- На выдачу влияют: скорость ответа (30+ мин — минус), отзывы, цена около рынка без резких скачков, «усталость» позиции после 30–45 дней без контактов.
